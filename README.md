# OAT Diagnostic — 50 Questions

A standalone GitHub Pages practice diagnostic built from the 2026 OAT User's Guide content specifications supplied by the user.

## Sections
- Biology: 10
- General Chemistry: 10
- Organic Chemistry: 10
- Physics: 10
- Quantitative Reasoning: 10

Reading Comprehension is intentionally omitted from this diagnostic.

## Run it
Open `index.html` locally, or upload the folder to a GitHub repository and enable GitHub Pages.

## Files
- `index.html` — interface
- `style.css` — styling
- `questions.js` — question bank, answers, explanations, and topic tags
- `app.js` — test logic, timer, scoring, results, and missed-question review

## Scoring note
The result uses a simple **estimated OAT-style 200–400 practice scale**. It is not the official ADA/OAT score-conversion algorithm.
